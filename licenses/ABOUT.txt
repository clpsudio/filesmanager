Files, by CLP Studio
====================

Files is made of CLP Studio's own code plus third-party components. Each
component keeps its own licence; the app as a whole is NOT distributed under a
single licence, and it is not "entirely Apache-2.0".

This screen has four sections:

1. CLP Studio's own code: the licence decision is PENDING. The proposed
   licence is the Apache License 2.0; it would apply only to code written by
   CLP Studio, and only once CLP Studio confirms it.
2. FFmpeg (LGPL-2.1-or-later): the audio decoders, with one MIT file
   (av_sscanf, from musl libc). That section says where the source code and
   the exact build configuration are published and how to replace FFmpeg.
3. Junrar (UnRAR licence): RAR archives. The UnRAR licence is not an
   OSI-approved open-source licence: the code may not be used to re-create the
   RAR compression algorithm, and modified versions must say it may not be
   used to develop a RAR (WinRAR) compatible archiver.
4. Other third-party components: AndroidX, Media3 (including its FFmpeg
   decoder Java and JNI code), Kotlin, Coil, Commons Compress, PdfBox-Android,
   Zip4j, Haze and others, under Apache-2.0, MIT, BSD or 0BSD. Every
   component, version and licence is in "All third-party components"; the
   notices those licences require are under "Notices".

Patents on audio codecs (for example AAC, AC-3/E-AC-3 and DTS) are a separate
matter from these copyright licences.
