Files, by CLP Studio
====================

Files is made of CLP Studio's own code plus third-party components. Each
component keeps its own licence; the app as a whole is NOT distributed under a
single licence, and it is not "entirely Apache-2.0".

This screen has three sections:

1. CLP Studio's own code: Apache License 2.0 (Copyright 2026 CLP Studio).
   It applies only to code written by CLP Studio. The Files name and logo
   are CLP Studio's; Apache-2.0 covers the code.
2. FFmpeg (LGPL-2.1-or-later): six audio decoders (FLAC, ALAC, G.711 A-law
   and mu-law, MP3, AC-3), with one MIT file (av_sscanf, from musl libc). That section says where the source code and
   the exact build configuration are published and how to replace FFmpeg.
3. Other third-party components: AndroidX, Media3 (including its FFmpeg
   decoder Java and JNI code), Kotlin, Coil, Commons Compress, PdfBox-Android,
   Zip4j, Haze and others, under Apache-2.0, MIT, BSD or 0BSD. Every
   component, version and licence is in "All third-party components"; the
   notices those licences require are under "Notices".

Files does not include any RAR library and does not open RAR archives.

AAC, E-AC-3, DTS and TrueHD audio are played by your phone's built-in
decoders when available; Files does not bundle decoders for them. Patents on
audio codecs are a separate matter from these copyright licences.
