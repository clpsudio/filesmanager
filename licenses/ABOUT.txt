Files, by CLP Studio
====================

Files is made of CLP Studio's own code plus third-party components. Each
component keeps its own licence; the app as a whole is NOT distributed under a
single licence, and it is not "entirely Apache-2.0".

- CLP Studio's own source code: the licence decision is PENDING. The proposed
  licence is the Apache License 2.0; it applies only to code written by CLP
  Studio, and only once CLP Studio confirms it.
- FFmpeg (audio decoders): LGPL-2.1-or-later, with one MIT file (av_sscanf,
  from musl). See "FFmpeg" for the source code and how to replace it.
- Junrar (RAR archives): the UnRAR licence. It is not an open-source licence:
  the code may not be used to re-create the RAR compression algorithm, and
  modified versions must say it may not be used to develop a RAR (WinRAR)
  compatible archiver. Full text under "Junrar".
- AndroidX, Media3 (including its FFmpeg decoder code), Kotlin, Coil,
  Commons Compress, PdfBox-Android, Zip4j, Haze and others: Apache-2.0, MIT,
  BSD or 0BSD. Every component, version and licence is in "All third-party
  components"; the notices those licences require are under "Notices".

Patents on audio codecs (for example AAC, AC-3/E-AC-3 and DTS) are a separate
matter from these copyright licences.
